## 标题

Once I press enter or perform other actions, the images in the document will disappear

## 标签

(无标签,Type: Bug)

## 问题描述

在文档中**按回车或执行其他操作后,文档中的图片消失**。此前只是偶尔出现,报告时(2024-02)已必然复现。报告者称有屏幕录像可提供(评论中未跟进)。

报告正文未说明文档格式,按扩展功能与图片编辑场景推断为 **Markdown 所见即所得编辑器(vditor)** 中编辑本地图片。

### 环境

- 扩展版本: 3.1.8(2024-02,距今较旧,当前 4.x 需先回归验证是否仍存在)
- VS Code: 1.86.2
- OS: Windows NT x64 10.0.22621(Windows 11)

## 期望行为

编辑操作(回车、输入、光标移动、切换预览/编辑模式等)不应导致图片丢失;图片应稳定显示,文档保存后图片引用完好。

## 实际行为

按回车或执行其他操作后,文档中的图片消失(报告者有录像,未附上)。

# 问题确认及解决

## 复现数据

复现文件: `test-workspace/markdown/test-markdown-cweijan-295-image-disappear.md`
生成脚本: 文本文件,直接维护

文件内容说明: 交互类 bug,文件为操作载体——若干段落文本之间穿插本地相对路径图片(png/jpg/gif,复用 `test-workspace/image/` 现有样本),图片前后各留可定位的光标停留点,便于在其附近执行回车/输入等编辑操作。

### 复现步骤

1. F5 调起扩展调试,打开复现文件(默认 markdownViewer,所见即所得模式);
2. 依次执行: 光标置于图片紧前/紧后按回车;在图片与文字间连续输入;对图片上方段落按回车拆分;切换预览/编辑模式再切回;
3. 每步操作后观察图片是否仍在渲染;
4. 预期: 图片始终显示,保存后 `![](../image/xxx)` 引用不变;
   实际(按 issue): 某次操作后图片消失(渲染消失或引用被改写/删除)。

注意: issue 报告于 v3.1.8(2024-02),先在当前版本按上述步骤回归——若已不复现,记录结论并关闭;若复现,再用二分(操作类型 × 图片位置 × 图片格式)缩小触发面,进入根因分析(vditor WYSIWYG 的 DOM ↔ markdown 同步链路)。
