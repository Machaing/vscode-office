## 标题

[BUG] markdown 在列表里嵌入表格的时候，修改表格的内容会删掉表格和列表内容之间的换行

## 标签

bug

## 问题描述

2022-11-18 由 huangcb01 报告，环境 OS: Windows / Linux，Extension Version: v2.9.0。

在 Markdown(WYSIWYG)中把表格嵌入列表项内部、表格与后续列表内容之间保留空行时，编辑表格单元格内容会导致空行被删除。报告者原话："当我修改表格第二行第二列的 2 时，表格跟"hello"之间的两个换行自动消失了。"

- 复现步骤(据正文整理)：
  1. 创建 Markdown 文件，在列表项内嵌入表格，表格后跟列表内容(如 "hello")，两者之间保留两个换行；
  2. 修改表格第二行第二列的单元格内容(值为 2)；
  3. 观察源文件。
- 正文附一张 GIF 演示(user-images 链接)展示问题发生过程，未以文本形式给出 Markdown 原文。
- 截至抓取时无任何评论，无维护者结论。

## 期望行为

编辑表格内容时，表格与后续列表内容之间的空行/换行保持不变，源码其余部分不被改写。

## 实际行为

编辑表格单元格后，表格与 "hello" 之间的两个换行被自动删除，内容挤到一起，列表结构被破坏(见正文 GIF 演示)。

## 复现数据

复现文件: `test-workspace/markdown/test-markdown-cweijan-157-list-nested-table.md`
生成脚本: 文本文件,直接维护

3. 预期: 表格与 `hello` 之间的空行保持不变；实际: 表格与 `hello` 之间的两个换行被自动删除，内容挤到一起、列表结构被破坏。
